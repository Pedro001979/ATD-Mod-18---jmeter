## Sobre o projeto

Projeto dedicado a **testes de carga e performance** utilizando Apache JMeter, explorando a capacidade de validar comportamento de aplicações sob diferentes níveis de demanda.

A iniciativa complementa minha atuação em QA Automation ao ampliar a visão de qualidade para além dos testes funcionais, considerando também desempenho, estabilidade e comportamento sob carga.

## Competências demonstradas

- Testes de carga
- Testes de performance
- Criação e organização de planos de teste
- Simulação de múltiplos usuários
- Análise de comportamento sob carga
- Identificação de possíveis gargalos

## Ferramenta

**Apache JMeter** — ferramenta open source para testes de performance de aplicações, APIs e outros serviços.

## Objetivo profissional

Demonstrar uma visão de **Quality Engineering**, considerando funcionalidade e também os requisitos não funcionais relacionados a desempenho e estabilidade.
